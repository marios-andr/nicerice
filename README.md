
# Nice Rice - A nice hyprland rice
This is a very nice dot file configuration of hyprland, quickshell, and some other packages.
The title does not deceive, it is indeed very nice. In fact, it's so nice that I use it daily,
which may not seem like much, but hey, what else can you ask for?

Requirements:

- hyprland
- qs
- awww
- hypridle
- playerctl
(optional):
- stow (for auto-setup with symlinks)
- khal (for calendar)
- vdirsyncer: (for calendar syncing with google)
  - Requires aiohttp-oauthlib (pip install aiohttp-oauthlib or sudo pacman -S python-aiohttp-oauthlib)
